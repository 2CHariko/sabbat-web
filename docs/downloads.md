Windows PowerShell：在下载目录执行，逐项对照上表。

```powershell
Get-ChildItem -File *.gpack | Get-FileHash -Algorithm SHA256 | Format-List Path,Hash
```

Linux：

```sh
sha256sum -c RESOURCES-SHA256SUMS.txt
```

macOS：

```sh
shasum -a 256 -c RESOURCES-SHA256SUMS.txt
```
