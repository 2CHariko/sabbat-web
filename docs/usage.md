# 使用说明

## 下载哪些文件

在线游玩必须下载以下 **四个文件**，文件名中的 `index` 和 `001` / `002` / `003` 分别代表索引与三个数据卷：

- `sabbat-compact-1536mib-index.gpack`
- `sabbat-compact-1536mib-001.gpack`
- `sabbat-compact-1536mib-002.gpack`
- `sabbat-compact-1536mib-003.gpack`

[逐项下载、国内访问备用链接及 SHA-256](downloads.md)。总计约 3.53 GB。四个文件放在同一文件夹，**无需解压、无需合并、无需改名**，在网页同时选中它们即可，选择顺序不限。不要把它们当作 ZIP/RAR 分卷。

在线玩不需要播放器 ZIP、介绍视频或 GitHub 自动生成的 `Source code (zip/tar.gz)`。`sabbat-web-v1.0.0.zip` 只供自行部署播放器使用，其中不含游戏资源。

## 配套版本

当前播放器为 v1.0.0，资源附件为 resources-v1.0.1，放在同一个 [v1.0.0 Release](https://github.com/2CHariko/sabbat-web/releases/tag/v1.0.0) 中。播放器与资源分别编号。

- compatibilityId：`af1da91da9b71dba500de477fcb1f2a713620f127ea0d85ee22872fc341196d0`
- resourceSetId：`32aa8886c1b8c9a946271b8ca3b313865795d474dccc4a3203c595e25cecec5a`

旧试玩资源、`resources-v1.0.0` 的旧兼容集合及其他分卷布局不能混用。网页会校验资源身份，缺卷时给出补选提示。

## 开始与保留进度

打开 [网页版](https://2chariko.github.io/sabbat-web/)，同时选择四个配套文件，或选择包含完整文件集的文件夹。手机无法使用目录选择时，可展开普通文件选择入口。建议横屏，先点击页面以启用声音。浏览器支持时可以记住文件位置，再次进入可能需要重新授权。

游戏内先保存，再通过 **播放设置 → 更多 → 存档备份与转移** 导出。换设备导入备份并确认重启，随后从原游戏读档界面继续。存档文件不包含游戏资源；清除浏览器数据前请先备份。

## 下载失败或校验不通过

原站连接慢时，改用下载表中的任一备用通道。不同通道可以分别下载不同文件，但必须来自此版本，下载后使用仓库中的校验表核对。第三方代理可能限流、失效或限制大文件，不保证满速；不要在代理站输入 GitHub 凭据或安装额外下载器。

若浏览器下载出 HTML 错误页、文件被截断或长度/哈希不符，换通道重新下载该文件。文件名相同不代表内容完整。

## 自行部署播放器

下载 `sabbat-web-v1.0.0.zip`，解压后使用 HTTP(S) 静态服务器托管，入口为 `index.html`。支持子目录部署。资源仍从本地选择；直接双击 HTML 文件不属于支持的启动方式。

用户已确认 PC Chrome、Android Chrome 可运行。宣传图中设备外框为示意；平板和手机布局使用真实页面触摸仿真录制。未声称逐一验证全部浏览器与系统组合。
