# 使用说明

## 配套资源

当前播放器：v1.0.0；需要完整的本地 .gpack 索引及全部分卷，不需要解压。当前兼容标识为 `af1da91da9b71dba500de477fcb1f2a713620f127ea0d85ee22872fc341196d0`，已验收集合为 `32aa8886c1b8c9a946271b8ca3b313865795d474dccc4a3203c595e25cecec5a`。旧试玩资源或 resources-v1.0.0 的旧兼容集合不能混用；网页会校验文件头和资源集合，缺卷时会给出补选提示。资源包不在此仓库分发。

## 开始与保留进度

在在线页面选择全部配套文件，或选择资源文件夹。无法使用目录选择的手机可展开普通文件选择入口。建议横屏；先点击页面以启用声音。浏览器支持时可以记住文件位置，再次进入可能需要重新授权。

游戏内先保存，再通过播放设置 → 更多 → 存档备份与转移导出。换设备导入备份并确认重启，随后从游戏读档界面继续。资源包和存档分别准备，清理浏览器数据前请备份存档。

## 下载版

下载 Release 中的播放器 ZIP，解压后通过 HTTP(S) 静态服务器托管，入口为 index.html。资源仍从本地选择，直接双击 HTML 文件不属于支持的启动方式。部署在子目录也可使用，所有运行文件均采用相对地址。
